# Mask-guided removal checks · 6 September 2026

This records software verification for version 0.6.0, not clinical or privacy accuracy. The method and teaching-template measurements are in [nifti-defacing.md](nifti-defacing.md). The earlier [0.5.0 volume-viewer pass](nifti-validation-2026-09-06.md) remains a historical record.

- The full Python suite passed on the development Mac: **337 tests**. Of these, 76 new defacing cases cover a non-symmetric synthetic volume, unequal voxel spacing, all 48 storage-axis permutations/flips, supported datatypes and byte orders, invalid masks/geometry/scaling/margins, request framing and exact regeneration of the public example. The additional server test checks authentication, origin restrictions, malformed input, no-store responses and stateless processing.
- The existing JavaScript unit suite passed: **16 tests**. No rendering or metadata dependencies were upgraded; both lockfiles retain their existing dependency versions.
- **Nine local NIfTI workflows** passed across Chromium, Firefox and WebKit at 1280, 390 and 320 pixels wide. Actual header-only downloads were independently checked, along with nine actual removal proposals and their removal maps. The independent verifier parses bytes and compares NumPy arrays; it does not call the defacer or NiBabel.
- **Six public workflows** passed across the same three engines at 1280 and 320 pixels. They serve under the GitHub Pages subdirectory and enforce same-origin requests, no API calls and no file-import or private-export controls. Four distinct comparison views are checked in every workflow, including the repeated return to the result. Accessibility checks reported no WCAG A/AA violations in the tested states and no page-level horizontal overflow.
- Finishing review added explicit external mask-review instructions, keyboard-accessible pan controls in all three planes, linked pan state across comparisons, and a focus-moving **Inspect comparison** shortcut. The final public run covered these controls in all three engines; targeted local Chromium runs confirmed them at 1280 and 320 pixels. CI runs the full local matrix on the committed version.
- Adversarial local browser cases verify that a mismatched uploaded mask, changed response bytes and a cancelled in-flight removal cannot enable an obsolete or unverified download. Changing inputs clears the prior review tick and result. Existing orientation/scaling mismatch and unavailable-graphics checks continue to run.
- The deterministic public build contains **151 allowlisted frontend assets**. It excludes the Python service, local JavaScript controller, file pickers, environment files and private input paths. Rebuilding the teaching comparison from the pinned MNI archive produces the same files and numerical report.

The one MNI average-head example has 1,082,035 voxels. At 5 mm, 67,221 non-zero voxels change, with zero changes inside the supplied brain mask or outside the removal selection. **16,512 of 62,236 supplied atlas face-region voxels remain outside the selection.** That is a useful counterexample to treating a successful software check as successful anonymisation. There is no independent-patient denominator, recognition attack result, clinical utility estimate or justified cohort confidence interval.

Artifacts are written under `output/nifti-deface/`, `output/nifti-browser/` and `output/nifti-preview/`. Defacing workflow records include browser/width, tested view count, accessibility results, export-check status and browser-workflow duration; this duration includes rendering and test overhead and is not algorithm-processing latency. CI uploads these folders for inspection.

Automated browser emulation does not establish physical iPhone/iPad, installed Safari, VoiceOver or TalkBack compatibility. Independent full-volume human QC, independently validated brain masks, diverse permitted patient cohorts, re-identification testing and downstream scientific utility measurements remain outstanding. Automatic brain segmentation and broader NIfTI/BIDS support are not implemented.
