# Teaching image credits

These 50 published MRI, CT and X-ray pictures are separate from the DICOM test fixtures. This is a collection of images and views, **not 50 independent patients or complete scan volumes**. Related views and false-colour composites are identified in the study notes.

The software is MIT licensed. **The images and thumbnails retain the individual licences below**, including ShareAlike where applicable. No contributor endorses this project. The source pages document the original provenance and permissions. Public-domain entries use the publisher’s designation, not a new CC0 dedication.

All images: re-encoded as JPEG, longest edge limited to 1600 pixels without enlargement, with 240-pixel thumbnails; source container metadata omitted. Colours, source annotations and framing retained. These transformations use the same licence as their source.

Selection checked 5 September 2026. Sources have at least 512 pixels on each side; published derivatives have at least 500 pixels on the short edge. Each was visually reviewed for visible anatomy and obvious personal text. This is not an expert clinical review or proof of anonymity. Images of heads retain recognisable anatomy.
