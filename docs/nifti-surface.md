# NIfTI workspace

Mode: Operate. Audience: students exploring 3D scans and authorised local reviewers.
The existing terminal design is retained. One large labelled plane and ordinary HTML controls take priority over simultaneous tiny panels or an automatic 3D head render.

The task is open, explore, inspect header findings, clean, acknowledge limits, save.
Public Pages contains curated teaching samples only. Local import and header cleaning
are separate from the static viewer. No defacing, diagnostic or anonymity claim.

Canvas directions are duplicated in explanatory text. All exploration can be performed
with keyboard/native controls; hover explanations also appear on focus and tap.
Physical-device and assistive-technology validation remain outstanding.
