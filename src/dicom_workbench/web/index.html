Six public images to learn with

Public test images from pydicom, sourced from NEMA and PCIR. Two teaching slices and four tiny 16 × 16 test images help you try different inputs. They load from your computer without an internet request.

We make documented metadata adjustments where needed; the image pixels stay unchanged. Sources and preparation ↗

!Metadata scrubbing is only one step. Selected areas can be erased. Remaining pixels and recognisable anatomy are not assessed. This is an educational prototype, not a clinical anonymiser.
